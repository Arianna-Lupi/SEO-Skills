# Rúbrica de revisión de contenido (basada en el diplomado)

Cada punto sale de una lección (entre paréntesis). Estado: **OK**, **Ajustar** o **Falla**. Severidad de un hallazgo: **alta** si afecta la confianza, la seguridad del usuario o la veracidad; **media** si debilita el valor o la intención; **baja** si es forma.

## 1. Intención y valor real
- [ ] La pieza responde la pregunta principal primero (S11 L2; práctica de coaches).
- [ ] El formato coincide con lo que la SERP premia (S8 L3).
- [ ] Aporta algo que el top 3 no tiene: caso, dato propio, ejemplo, opinión experta (S11 L2, S14 L12).
- [ ] No hay relleno: contexto secundario que el usuario no pidió, repeticiones, introducciones largas.

## 2. E-E-A-T
- [ ] **Experiencia:** hay vivencia de primera mano (casos, pruebas, fotos o videos propios) (S7 L5).
- [ ] **Especialización:** profundidad correcta para la audiencia, términos técnicos explicados (práctica de coaches).
- [ ] **Autoridad:** trayectoria visible y presencia externa; si no hay dato, `pendiente de dato` (S7 L5).
- [ ] **Confiabilidad:** quién escribe está claro, "Sobre nosotros" sólido, contacto visible, sitio seguro (S7 L5).
- [ ] Autoría con bio verificable y, si el tema es técnico, coautoría o revisión de un experto (S7 L5).

## 3. Veracidad
- [ ] Cada cifra, estudio o nombre técnico tiene fuente primaria o institucional (S14 L12).
- [ ] No hay testimonios, credenciales, números de proyectos ni promesas inventadas (práctica de coaches).
- [ ] Sin superlativos sin evidencia ("el mejor", "garantizamos posiciones") (práctica de coaches).
- [ ] Datos vigentes: se reemplazó lo obsoleto (S10 L5).

## 4. Humanización (si hubo IA)
- [ ] Mínimo 3 puntos con opinión o experiencia propia (S14 L12).
- [ ] Voz de marca consistente (3 adjetivos definidos antes de escribir) (S11 L2).
- [ ] Sin frases genéricas de relleno; leído en voz alta suena natural (S14 L12; práctica de coaches).
- [ ] Informe de qué se eliminó o cambió de la IA, si el flujo lo exige (práctica de coaches).

## 5. Escaneabilidad y experiencia
- [ ] Párrafos de 3 a 4 líneas, negritas, listas, encabezados descriptivos (S11 L3).
- [ ] Jerarquía H1 a H3 sin saltos; el texto va tras cada H2 o H3, los encabezados no desarrollan contenido (S8 L5; Diana #56).
- [ ] CTA claro y proporcional al tipo de página; un informativo no debe parecer un embudo (S7 L6; práctica de coaches).
- [ ] Imágenes con nombre descriptivo y Alt Text (S11 L1).

## 6. Citabilidad para IA (opcional)
- [ ] Primer párrafo con respuesta directa en menos de 40 palabras (S14 L13).
- [ ] Datos comparativos en tabla HTML limpia; listas para pasos o requisitos (S14 L13).
- [ ] FAQ solo con preguntas reales que están visibles en la página (S14 L13).

## Veredicto
- **Lista:** ningún "Falla" y como mucho 2 "Ajustar" de severidad baja.
- **Publicar con ajustes:** "Ajustar" de severidad media, ninguno alto.
- **Reescribir secciones:** hay "Falla" en intención, valor o veracidad.
- **No publicar:** cifras inventadas, credenciales falsas, tema sensible sin fuente ni revisión.
