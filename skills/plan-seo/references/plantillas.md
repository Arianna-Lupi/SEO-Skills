# Plantillas: Plan SEO (formato del diplomado)

## 1. Cuestionario SEO para el cliente (S2 L12)

| Bloque | Preguntas guía |
|---|---|
| Negocio | Historia, productos o servicios principales, público objetivo, ubicación |
| Objetivos | ¿Qué espera lograr (ventas, leads, marca)? ¿Qué venta o contacto vale más? |
| Competencia | Competidores directos en el mundo real y en Google |
| Historial SEO | ¿Se hizo SEO antes? ¿Penalizaciones, migraciones, cambios de CMS? |
| Accesos | Search Console, Analytics, CMS, hosting si aplica |
| Contexto extra | Estacionalidad, cobertura geográfica, presupuesto de tiempo (práctica de coaches) |

No hay número fijo de preguntas: depende del proyecto y del nicho (Ari, #322). Reunión de onboarding más cuestionario.
